# Attribution

This project retains the educational three-stage face-recognition workflow used by the original prototype:

1. face dataset capture
2. LBPH training
3. real-time face recognition

The original training script explicitly credited:

- Marcelo Rovai / MJRoBot
- the OpenCV face-recognition educational project at `github.com/Mjrovai/OpenCV-Face-Recognition`
- earlier work referenced in that script by Anirban Kar / `thecodacus`

This cleaned repository substantially restructures the implementation for ESP32-CAM capture, configurable paths, CLI usage, error handling, privacy, and public GitHub hygiene.
